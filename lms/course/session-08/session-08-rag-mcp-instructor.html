Teaching point

RAG is not “uploading a PDF.” It is an evidence-selection system.

The entire session on one slide

One agent. Five jobs.

HearVoice / chat receives a request.
RetrieveFind the smallest relevant evidence.
ReasonAnswer or decide from that evidence.
ActCall a bounded Make tool through MCP.
VerifyCheck the answer and tool result.

If students remember this chain, the session worked.

Say this

Walk left to right. “RAG handles retrieve. MCP standardises how the agent discovers and calls the Make tool. Make executes the rule.”

Part 1 · RAG in plain English

RAG is an open-book exam for an AI.

01 · SPLIT

Break documents into useful passages.

02 · RETRIEVE

Find passages closest to the question.

03 · ANSWER

Use evidence; refuse to invent what is absent.

Say this

“The model is still the same model. We are changing what evidence reaches it at answer time.”

Board work

Write: document → chunks → ranked chunks → answer.

Misconception

RAG does not train or fine-tune the model.

Part 2 · MCP in plain English

MCP is a universal tool socket for AI.

AI hostClaude, an agent, or another client
MCP clientdiscovers and calls capabilities
⇄
MCP serveradvertises an explicit contract
Make toolruns the bounded workflow

The model proposes a tool call. The host controls the connection. The server executes only the exposed capability.

Say this

Use the USB analogy once, then return to exact roles: host, client, server, tool.

Important

MCP is not the model, not the database, and not the automation itself.

Question

Ask: Why expose one named tool instead of the entire Make account?

Do not mix these up

RAG decides what to know.
MCP decides what can be called.

RAG · READ PATH

Question → evidence → grounded answer

Usually reads. The risk is bad or manipulated evidence.

MCP TOOL · ACTION PATH

Intent → structured arguments → result

May write. The risk is excess authority or an unsafe contract.

Say this

“RAG can tell you whether an enterprise lead needs approval. A tool can prepare the draft and return the routing status.”

Check

Ask students to label three examples as knowledge or action.

Examples

Refund policy = knowledge. Create invoice = action. Retrieve invoice status can be either a read tool or a document query depending on source.

Red-team the system

What could still go wrong?

BAD RETRIEVAL

Old policy wins.

BAD ARGUMENT

Consent becomes true.

TOO MUCH POWER

Tool can send or delete.

BAD SUMMARY

Agent claims more than result.

Trust comes from evidence, permissions, contracts, approval, and tests—not from a clever system prompt.

Activity
