# Session 04 surprise quiz · learner form

**Quiz ID:** `quiz_s4_product-build-judgment`  
**Quiz version:** `S4-SQ-v1`  
**Assessment class:** counted surprise-quiz candidate; may be armed instead as a non-counted retention check  
**Items:** 7 single-answer multiple choice  
**Time limit:** 6 minutes  
**Score formula:** `correctOptionId matches ÷ 7 × 100`; the LMS stores the unrounded count and rounds the displayed percentage to one decimal  
**Mastery marker:** 5/7 for instructional follow-up  
**Answer release:** attempt receipt only at submit; score, correct options, rationales and item feedback release after the configured section delivery window closes  

Choose the best answer. The LMS may shuffle display order; the stable option IDs below remain unchanged and are never replaced by a display letter or array index.

## `S4-Q1@1`

Three products have credible revenue. Which is the strongest one-hour classroom target?

- `S4-Q1-FEATURE-LIST` — The one with the longest official feature list
- `S4-Q1-END-TO-END` — The one whose valuable end-to-end behavior can be built and verified within the real constraints
- `S4-Q1-HIGHEST-MRR` — The one with the highest MRR, regardless of architecture
- `S4-Q1-VISUAL` — The one with the most visually impressive landing page

## `S4-Q2@1`

Which implementation treats an unavailable Instagram integration honestly?

- `S4-Q2-TIMER-CONNECTED` — Show “Connected” after a timer so the flow feels complete
- `S4-Q2-PRESENTATION-ONLY` — Remove the label but explain the mock in the final presentation
- `S4-Q2-PASTE-PASSWORD` — Ask the student to paste their Instagram password
- `S4-Q2-LABELLED-FIXTURE` — Load fictional posts and label the action “Demo import — no Instagram connection”

## `S4-Q3@1`

Which addition most improves a vague first prompt?

- `S4-Q3-OPERATING-CONTRACT` — A specific user/job, state/actions, failure boundaries and observable acceptance tests
- `S4-Q3-WORLD-CLASS` — “Make it world-class”
- `S4-Q3-ADVANCED-STACK` — “Use the most advanced stack”
- `S4-Q3-COPY-SCREENSHOT` — A screenshot and “copy this exactly”

## `S4-Q4@1` · volatile

Under Lovable’s documented behavior at the Session 4 source check, what happens in Plan mode?

- `S4-Q4-AUTO-PUBLISH` — It publishes automatically when the plan is complete
- `S4-Q4-EDIT-FREE` — It edits code immediately and costs nothing
- `S4-Q4-NO-EDIT-ONE-CREDIT` — It never changes code until approval, and each Plan message costs one credit
- `S4-Q4-ALWAYS-CHEAPER` — It always costs less than Build mode

## `S4-Q5@1` · volatile

A student has a tested app and zero build credits. What is the best current publication move?

- `S4-Q5-PUBLISH-INCOGNITO` — Use the Publish dialog, then verify the live URL in incognito
- `S4-Q5-EDITOR-PREVIEW` — Submit the editor preview
- `S4-Q5-BUY-CREDITS` — Buy credits before the deadline
- `S4-Q5-CHAT-SHIP` — Ask Lovable in chat to “ship it”

## `S4-Q6@1` · volatile

Why can a student not assume ten days on Lovable Free equals fifty usable build credits?

- `S4-Q6-CANNOT-PUBLISH` — Free accounts cannot publish
- `S4-Q6-PLAN-FIVE` — Plan mode costs five credits per message
- `S4-Q6-HOSTING-ONLY` — Credits are used only for hosting
- `S4-Q6-EXPIRY-CAP` — Daily build grants do not roll over and the Free plan is capped at 30 per month

## `S4-Q7@1`

Which submission is the strongest verification evidence?

- `S4-Q7-MODEL-CLAIM` — A long list of features Lovable said it implemented
- `S4-Q7-REPRODUCIBLE-EVIDENCE` — A public URL plus timestamped PASS/FAIL/NOT RUN log, negative test, incognito peer check and known limitations
- `S4-Q7-UNMAPPED-SCREENSHOTS` — Three screenshots with no test IDs
- `S4-Q7-LAPTOP-CLAIM` — “It worked on my laptop”

## Learner release boundary

Do not expose answer IDs, right/wrong state, item rationales or distractor feedback in the quiz payload, preview, search index or export before the delivery window closes. When multiple sections use `S4-SQ-v1`, the delivery window ends only after the last scheduled participating section closes. An instructor may use a section-local release only when that section has a distinct, non-reused quiz version.
