## Entry / in-lesson diagnostic

### S09-D-01A — What earns the proof click?

- **Version/staleness:** v0.1; review 17 October 2026; durable.
- **Outcome:** C9.
- **Purpose/demand:** formative diagnostic; apply.
- **Stream/context:** Sales; family `S09-D-01`.
- **Difficulty/time:** easy; 45 seconds.
- **Prompt:** Which opening gives a sales recruiter the clearest 60–90 second scan?
- **Options:**
  - A. “Tools used: nine AI logos,” followed by prompt screenshots.
  - B. “Enterprise sales candidate: built an evidence-grounded next-action workflow; four assigned attempts exposed an unsupported claim, so I added seller approval and reran it,” with proof links.
  - C. A two-minute animation with no role or decision.
  - D. A raw repository file list.
- **Correct answer:** B.
- **Rationale:** B states role, work, evidence, failure/fix, human boundary, and next proof without overclaiming.
- **Distractors:** A is a tool museum. C hides the decision and evidence. D may contain proof but does not guide a time-poor reviewer.
- **Feedback:** “Lead with role → decision/work → result → failure/fix → proof—not tools or artifacts.”
- **Accessibility:** all information is textual; no video viewing required.

## Delayed-retrieval Form A

### S09-R-01A — Recruiter-proof order

- **Version/staleness:** v0.1; review 17 October 2026; durable.
- **Outcome:** C9.
- **Purpose/demand:** delayed retrieval; analyze.
- **Stream/context:** Sales; family `S09-R-01`.
- **Difficulty/time:** medium; 70 seconds.
- **Prompt:** A candidate has an account brief, working workflow, four assigned attempts, a claim failure/fix, repository, and a product video. Which public order is strongest?
- **Options:**
  - A. Tool list → all prompts → video → repository → role.
  - B. Target sales role and account decision → evidence-grounded next action → precise attempt result → unsupported-claim failure/fix → limitation/next test → selected proof links.
  - C. Repository tree → every source → full logs → summary.
  - D. Video → “validated by users” → company logo → contact details.
- **Correct answer:** B.
- **Rationale:** B earns attention with role-relevant judgment, then makes evidence and limits inspectable without forcing a full repository audit.
- **Distractors:** A and C lead with production debris. D overclaims task attempts and risks affiliation confusion.
- **Feedback:** “The public scan earns the next click; the proof view then supports inspection and reproduction.”
- **Accessibility:** no design/layout assumption; order is given in text.

### S09-R-02A — Public, private, or excluded

- **Version/staleness:** v0.1; review 17 October 2026; review institutional data-retention policy before delivery.
- **Outcome:** C8, C9.
- **Purpose/demand:** delayed retrieval; evaluate.
- **Stream/context:** Finance — Investment Banking; family `S09-R-02`.
- **Difficulty/time:** hard; 90 seconds.
- **Prompt:** An IB portfolio contains: a sourced public filing calculation, a labelled simulated data-room table, an anonymized run log, a hidden assessment key, and an API token accidentally pasted into a notebook. What is the correct treatment?
- **Options:**
  - A. Make everything public to prove transparency.
  - B. Public: sourced calculation and appropriately summarized/labelled simulated evidence; private proof: anonymized detailed run log; exclude/quarantine: hidden key and token, then rotate/remediate the token.
  - C. Keep the token private but stored in the proof view.
  - D. Remove the simulated label so the project appears authentic.
- **Correct answer:** B.
- **Rationale:** Public proof must be safe and truthful; detailed valid evidence can remain private; secrets and hidden tests are not portfolio evidence and require remediation.
- **Distractors:** A exposes restricted data. C still stores a live secret. D turns legitimate simulation into deception.
- **Feedback:** “Transparent does not mean public-by-default. Classify evidence by purpose, access, consent, and risk; secrets are removed, not merely hidden.”
- **Accessibility:** categories are explicit; “rotate” means invalidate and replace the exposed token.

### S09-R-03A — Affiliation and provenance problem

- **Version/staleness:** v0.1; review 17 October 2026; review disclosure copy before delivery.
- **Outcome:** C8, C9.
- **Purpose/demand:** delayed retrieval; diagnose.
- **Stream/context:** Finance — Corporate Finance; family `S09-R-03`.
- **Difficulty/time:** medium; 75 seconds.
- **Prompt:** A candidate page says “Bharti Airtel Capital Allocation AI — built for Airtel,” uses the official logo as the dominant brand, and presents instructor-supplied synthetic forecasts as internal company data. What is the best correction?
- **Options:**
  - A. Keep it because a favourite-company project should feel real.
  - B. Label it an independent educational project not affiliated with the company, use restrained attribution, identify forecasts as synthetic/calibrated, and state the candidate's actual contribution.
  - C. Remove all provenance so the page is shorter.
  - D. Add “confidential” to make the simulated data sound credible.
- **Correct answer:** B.
- **Rationale:** B corrects affiliation, data provenance, and ownership without discarding the legitimate work sample.
- **Distractors:** A and D intentionally misrepresent. C hides the evidence needed for trust.
- **Feedback:** “Recruiter credibility depends on precise affiliation, data, and contribution labels—not simulated insider access.”
- **Accessibility:** no logo viewing required; the misleading elements are described.

### S09-R-02B — Public, private, or excluded

- **Version/staleness:** v0.1; review 17 October 2026; review HR/privacy policy before delivery.
- **Outcome:** C8, C9.
- **Purpose/demand:** parallel retake; evaluate.
- **Stream/context:** Human Resources; family `S09-R-02`.
- **Difficulty/time:** hard; 90 seconds.
- **Prompt:** An HR portfolio contains an aggregated synthetic subgroup test, a policy citation, anonymized detailed attempts, raw real resumes used without permission, and an unconsented employee recording. What treatment is correct?
- **Options:**
  - A. Public: aggregated labelled synthetic result and policy citation; private if necessary: minimal anonymized valid attempts; exclude/delete or quarantine per policy: unauthorized resumes and recording.
  - B. Publish everything after removing names.
  - C. Keep unauthorized resumes in the private proof view because recruiters value realism.
  - D. Present synthetic results as real to avoid explaining the dataset.
- **Correct answer:** A.
- **Rationale:** De-identification alone does not cure unauthorized collection/use; valid synthetic and minimal consented evidence can be truthful proof.
- **Distractors:** B and C ignore permission, purpose, and retention. D deceives about provenance.
- **Feedback:** “Private is not a loophole. Use only authorized, minimal evidence and label synthetic data accurately.”
- **Accessibility:** sensitive examples are hypothetical and contain no actual personal data.

### S09-R-03B — Affiliation and provenance problem

- **Version/staleness:** v0.1; review 17 October 2026; review brand/disclosure copy before delivery.
- **Outcome:** C8, C9.
- **Purpose/demand:** parallel retake; diagnose.
- **Stream/context:** Marketing; family `S09-R-03`.
- **Difficulty/time:** medium; 75 seconds.
- **Prompt:** A speculative Nykaa campaign page says “Official Nykaa AI Launch,” uses an unauthorized celebrity voice, and reports three assigned peer preferences as “market-proven conversion.” Which correction is strongest?
- **Options:**
  - A. Add more generated images so the page feels official.
  - B. Apply the independent-project disclaimer, remove unauthorized voice, label synthetic assets, report only three formative assigned responses, and state the next valid experiment.
  - C. Keep the claim but add an asterisk with no explanation.
  - D. Move the misleading statements to the private proof view.

- **Rationale:** B corrects affiliation, identity rights, evidence inflation, disclosure, and next-test logic.
- **Distractors:** A increases misrepresentation. C remains materially misleading. D does not make deceptive content acceptable.
- **Feedback:** “Do not borrow credibility from a company, identity, or inflated result. Recruiter trust comes from exact labels and limits.”
- **Accessibility:** voice is discussed textually; no audio playback required.

## Scoring, threshold, and retake

- Entry diagnostic is unscored; use results to decide whether to reteach the proof order before portfolio building.
- Delayed Form A: one point each; three total; no partial credit.
- **3/3:** ready. **2/3:** Developing; assign proof-order or publication-boundary repair. **0–1/3:** prerequisite repair and private facilitator signal.
- Students below 3/3 see rationale and complete the repair card before one Form B retake.
- Preserve first and retake results separately; latest informs readiness only. Publication blockers override quiz performance.
- Randomize option order, not scenario facts or A/B pairing.
- Retrieval mastery is 90% across delayed checks.

## Item-quality checks

- Two reviewers independently answer all items; rewrite any disagreement.
- Compare A/B pairs for proof volume, risk visibility, reading load, and cognitive demand.
- Validate disclosure, privacy, brand, identity, and secret-handling wording against institutional policy before release.
- Confirm Sales, IB, Corporate Finance, Operations, HR, and Marketing are portrayed as credible work, not merely risk examples.
- Ensure no answer depends on knowing a particular portfolio, repository, or scanner UI.
- Accessibility: screen-reader order, no color/logo/media dependency, plain-language definitions, appropriate extra time.
- Pilot review: difficulty, time, omitted response, distractor function, discrimination, and differential performance by section/stream where feasible.
- Version/retire items; never silently edit a live form.
