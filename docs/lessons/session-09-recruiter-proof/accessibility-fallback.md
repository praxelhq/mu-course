# S09 Accessibility and Fallback

Public and proof views must be keyboard/screen-reader usable with headings, link purpose, visible focus, meaningful alt text, transcripts/captions, data tables and no color-only status. A linear HTML/tagged PDF case page plus zipped proof bundle is equivalent to a hosted site. A text or captioned-recorded defence is equivalent to live speech; accent/speed are not graded.

If hosting/auth/network fails, switch to STATIC_FALLBACK: local page, checksummed bundle, printed/CSV `data/synthetic-proof-manifest-learner.csv` and receipt. Never distribute the evaluator manifest containing planted-risk/action fields. Blind scan and random proof continue. Broken vendor uptime is incident evidence, not learner failure. Extra time uses secure pause/resume and a fresh random prompt.

No public posting, social reach, camera, paid host or complex Git command is required. Facilitator may help with access mechanics, never select evidence or explain the defence. All routes preserve public/private classification, scan, reproducibility, quarantine, provenance and proof.
