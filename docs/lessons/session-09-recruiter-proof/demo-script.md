# S09 Demo — From Tool Museum to Proof Story

**7 minutes; S09-DEMO-01 synthetic project.**

1. Show Page A for 20 seconds: logos, “built with 12 AI tools,” animated screenshots, no decision. Ask role/result.
2. Show Page B: “FP&A analyst: corrected a currency mapping that changed capex recommendation; staged approval; proof.” Ask which link you would open.
3. Transform A live into Scan → inspect → reproduce: role/context; consequential decision; evidence; mechanism; failure/fix; result; limit; next test; one proof CTA.
4. Click the number: public claim → manifest ID → synthetic row/formula → run receipt. Click failure: v1/v2 diff → rerun.
5. Reveal planted API key, raw tester name and company logo implying endorsement. Quarantine them; rotate key in narrative; replace raw record/logo with redacted ID and non-affiliation label.
6. Run static replay in a clean view. It works without original chat or paid account.
7. Randomly select “Why this was your decision, not the model’s?” Open prediction, rejected change and defence boundary.

Fallback is a printed pair, proof index and redaction stickers; learner makes the same scan, classification and trace.
