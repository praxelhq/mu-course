# S09 Instructor Runbook — From Tool Museum to Proof Story

## Setup

Load paired demo pages (tool museum vs decision story), one secret/affiliation failure, S09-FX-MANIFEST-01, public/private templates, V08/V09, static host, random proof selector and privacy escalation. Never ask students to publish publicly in class.

| Min | Move | Evidence/check | Recovery |
|---:|---|---|---|
| 0–6 | public/private/exclude retrieval | raw peer logs marked public | distinguish claim from protected evidence |
| 6–12 | 20-second recruiter scan; vote | tool-rich page wins prediction | reveal which proof link opened |
| 12–27 | teach mechanism; transform demo; expose secret/logo | claim→proof→replay visible | quarantine, replace with safe static evidence |
| 27–32 | lock recruiter/lead/vulnerable claim | “AI enthusiast” as role | require named hiring decision |
| 32–76 | triage; build public and proof views | proof pack as junk drawer | require index and exact evidence pointers |
| 76–94 | V08/V09 scan and repair | screenshot as run proof | link execution/test or labelled replay |
| 94–104 | blind 60–90 sec scan | author coaching | restart with artifact-only reviewer |
| 104–112 | random proof defence | rehearsed favourite only | LMS selects claim/number/branch/contribution |
| 112–120 | freeze; predict S10 break | public before approval | keep private/unlisted until gate passes |

Debrief: “What did the recruiter see first? Which click proved rather than repeated the claim? What moved from public to private or exclude?” Reward a short truthful route and volunteered limit, not site polish.

Across sections, use identical scan time/questions, repository requirements, random prompt classes and publication thresholds. Trained human scores all judgment; peers only observe; safety/affiliation flags moderate before publication.
