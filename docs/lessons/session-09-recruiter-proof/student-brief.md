# S09 Student Brief — Recruiter Scan, Auditor Click

**Role:** candidate for the pathway role; **decision owner:** recruiter/hiring manager decides whether to inspect; evaluator decides whether proof is valid. Independent educational project, not company work or endorsement.

## Mission

Build two doors: a public case page that makes role, decision, evidence, prototype, result, failure/fix and limit legible in 60–90 seconds; and a private proof index that lets an authorized reviewer reproduce and challenge the work.

## Inputs/rules

Use S07/S08 frozen artifacts, S09 pathway card, proof manifest fixture/template, V08 repository structure and V09 publication checklist. Classify every item public/private/exclude. Each public claim links to access-appropriate proof; every private link is access-tested. Tool list is secondary. Never publish secrets, PII, raw peer evidence, restricted assets or hidden case keys.

## Submit

Target recruiter/lead prediction; privacy/proof map; public v2; private proof index; repository/checkpoint; PROVENANCE; LIMITATIONS; manifest; scan results/repairs; blind recruiter scan; random defence receipt; publication state. Success means a reviewer can scan, inspect and reproduce—not simply admire.
