# S09 Solution Anchors — Recruiter Proof

| Level | Observable anchor |
|---|---|
| Pass | public page makes role/decision/evidence/result/failure/limit legible; one CTA opens valid proof; private index reproduces; manifest/provenance complete; unsafe items quarantined; blind scan accurate; random defence opens evidence and owns boundary |
| Partial | story understandable but proof scattered, replay fragile, limit buried or reviewer needs coaching |
| Fail | tool museum, unsupported claims, screenshots-only proof, broken/private links, no random defence or original chat required |
| Unsafe | secret/PII/raw peer evidence, false endorsement/internal access, unlicensed media, hidden synthetic data or private bundle public |

Common 70%: scan story 15; proof/reproduction 20; provenance/privacy 15; failure/ownership 10; access/defence 10. Pathway 30% is the role-specific judgment in content-packs.md.

Likely disagreement: attractive page versus strong proof. Moderator reads text-only, follows one randomly selected claim and reproduces one run. Polish, tool count, coding and popularity are excluded. Transfer: learner gets a fresh manifest item and must classify it, trace it and decide publish/private/exclude in 90 seconds.
