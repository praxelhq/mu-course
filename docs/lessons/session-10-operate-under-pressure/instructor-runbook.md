# S10 Instructor Runbook — Transfer Arena

## Non-negotiable setup

Freeze section-secured variants, V10/rubric, clean workspaces, known/hidden-equivalent tests, offline packs, permitted-resource copy, random defence seed, incident clock and primary/double-score queues. Verify original chats unavailable without blocking accessibility tech. Demonstrate only neutral toy inventory.

| Min | Instructor move | Check | Intervention boundary |
|---:|---|---|---|
| 0–2 | show toy output; freeze inspect-vs-reprompt prediction and confidence | every learner commits before evidence | no assessed schema; paper vote is equivalent |
| 2–6 | controlled entry/readiness | workspace, fallback, allowed resources | solve access only; record incident |
| 6–11 | reveal toy duplicate-schema evidence and patch | prediction changes or holds for evidence-linked reason | never show assessed domain/answer form |
| 11–15 | rules scenarios | clean AI and safe escalation understood | explain rules, not case |
| 15–21 | release assigned case; lock prediction | owner, quality bar, boundary, confidence | no tools until commitment |
| 21–46 | silent individual diagnosis/patch | substantive diff and evidence pointer | tool support only; no strategic hint |
| 46–58 | critical + guardrail run | equivalent before/after | classify platform fault separately |
| 58–72 | decision and freeze; V10 | action/owner/limit/provenance | one mechanical message, no answer |
| 72–80 | bounded retry/mechanical repair | strategic content remains frozen | new version and incident trail |
| 80–90 | random defence assignment/prep | prompt cannot be self-selected | access support only |
| 90–104 | triad rehearsal | 90 sec + one evidence question | peers observe, never grade |
| 104–112 | private proof attach | public remains frozen | quarantine leaks |
| 112–120 | calibration/close/appeals | evidence-based confidence | explain process, no scores |

If many learners ask the same content question, do not answer publicly; log potential case defect and pause/replace only through incident protocol. Debrief asks what changed confidence and where safe refusal beat completion. Human primary scores every packet; ≥10% stratified blind double-score; all flags/appeals moderate. Later-section keys remain embargoed.
