# S10 Source Pack, Security and Provenance

Learner sources: assigned synthetic case/data version, supplied policy/reference snapshot, clean supported shell, own frozen S09 bundle/notes and approved tools. All fictional context is visibly labelled independent course simulation. No real company, person, deal, employee, customer or confidential record.

S10-FX-VARIANTS-01 registry and the A/B `synthetic-transfer-case-payloads*.json` and `synthetic-transfer-test-fixtures*.json` pools are authored source masters, not learner evidence. A/B differ in material defect and evidence, not merely surface labels; delivery additionally freezes learner-specific numeric/label seeds and never reuses an exact payload in adjacent sections. Hidden defect keys, answer anchors, section mapping and test expectations are evaluator-only, split from learner payloads and encrypted/access-controlled in implementation, and embargoed until all sections close. Demo uses unrelated toy inventory and separate schema.

Each case source records fixture ID/version/checksum, author, creation/review date, synthetic/public label, data dictionary, equivalence group and staleness rule. Any public reference includes URL/publisher/access date/snapshot/license. At T-30/T-2 days, two reviewers verify accuracy, link availability, regulated wording, equivalent reading/calculation load, no answer collision with quizzes/demo and no exposed key.

A compromised/defective case is retired, all affected attempts frozen, and an equivalent fresh variant issued. Never silently edit live data or use real learner/company/private records.
