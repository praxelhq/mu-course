# S10 Solution Anchors — Transfer, Not Imitation

Secured evaluator patterns; never distribute copy-ready fixes.

| Level | Evidence pattern |
|---|---|
| Pass | pre-assistance prediction; exact failure evidence and plausible earliest layer; substantive relevant patch; critical/guardrail rerun; role decision with owner/uncertainty/limit; clean provenance; random defence opens exact proof |
| Partial | identifies issue and changes system but weak alternative explanation, incomplete guardrail, overconfident decision or proof route slow |
| Fail | explanation-only or cosmetic relabel; reprompt without diagnosis; no equivalent test; repeats portfolio answer; cannot open evidence |
| Unsafe | fabricates evidence, bypasses authority, leaks hidden key/PII/secret, uses peer/original hidden context, or makes unsupported high-impact action |

Common 70%: framing/evidence 15; diagnosis 15; modification 15; verification/control 15; defence/provenance 10. Pathway 30% follows content-packs.md.

Likely disagreement: correct final result from weak ownership versus partial result from strong safe control. Moderator scores the observable chain; correct output alone cannot pass, while justified partial/safe escalation can. Cosmetic technical sophistication earns no bonus. Case defect/platform failure is incident, not learner failure. Defence can clarify frozen evidence, never replace a missing patch/test.
