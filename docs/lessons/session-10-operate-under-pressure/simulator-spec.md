# S10 Simulator Spec — Clean-session Transfer Arena

**Mission:** S10-SIM-01 · **Validator:** V10 · secured individual assessment

READY → ID_VERIFIED → CLEAN_WORKSPACE_BOUND → CASE_ASSIGNED → PREDICTION_COMMITTED → TOOLS_UNLOCKED → PATCH_SAVED → TESTS_RUN → DECISION_SAVED → FROZEN_V1 → MECHANICAL_REPAIR/FROZEN_V2 → DEFENCE_ASSIGNED → DEFENCE_COMPLETE → PRIVATE_PROOF_ATTACHED → AUDIT_PENDING. Side: INCIDENT, QUARANTINED, EQUIVALENT_REASSIGNMENT, ACCESS_PAUSE. Illegal: original context/peer access; pre-prediction tools; overwrite; strategic answer feedback; public transfer claim before audit.

Assignment balances pathway/starting band and rotates section-secured contexts/defects. Known test confirms mechanics; hidden-equivalent test checks same construct without answer trivia. Learner can repair, hold, refuse or escalate. Reset requires incident authority, fresh equivalent variant and preserved history.

Feedback before freeze is deterministic only: missing IDs/links/test/provenance, never defect answer. Model assistance operates inside clean workspace and is declared, not a grader. Triad provides proof/honesty/boundary observation after strategic freeze. Trained human primary scores all packets; moderator handles flags/borderlines/appeals; ≥10% blind double-score.

Controls: pause section, activate offline, replace defective variant, extend approved timing, quarantine unsafe output and freeze embargo. Instructors cannot reveal keys, hints or select defence prompts.

Events: clean_session_verified; case_assigned; prediction_committed; tools_unlocked; patch_saved; test_started/completed; decision_saved; packet_frozen; V10_result; mechanical_repair_saved; defence_prompt_assigned/completed; sprint_confidence_calibrated; proof_attached; incident/equivalent_variant_issued. Sprint confidence is formative and excluded from the separate pre/post growth dataset. Actor/section/variant/version/privacy/idempotency required.

Offline sealed pack supplies evidence tables, system-state cards, patch choices plus open specification, before/after test key and random defence envelope; it preserves substantive diagnosis/decision rather than trivia.
