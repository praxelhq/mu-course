# S04 Session Contract — Package Judgment v1.0

**Source state:** Authored; self-validation recorded in `self-audit.md`. **Time:** 120 live minutes + 30–45 minutes postwork. **Capabilities:** C4, C8. **Canonical outcomes:** L04-O1–L04-O6 (aliases S4-O1–S4-O6). **Canonical validator:** V03; all local checks nest under it. **Common mechanism:** `Trigger → Inputs → Judgment → Output → Checks → Stop/escalate`.

## Learner promise

In two hours, turn one piece of professional judgment into a portable method that a stranger can run, break, and trust without access to the author's chat history.

## Observable evidence and portfolio contribution

The learner freezes `Method Layer v1`: method contract, input/output schema, normal/messy/non-trigger runs, peer clean-run trace, hidden-change before/after receipt, provenance, and a 60-second human-boundary defence. This becomes the method layer of the AI operating prototype—not a standalone prompt trophy.

## Prerequisites and dependencies

- Approved Work Sample Brief; Session 2 source/claim ledger; Session 3 grounding decision.
- Supported LMS method-card runner or printed executor cards; no paid account or code required.
- Demonstration uses `S04-DEMO-FOCOS-01`; assessment uses the learner's assigned `S04-*-PACK-01` and hidden variant. Copying the demo cannot pass.

## Release boundary

In class, feedback is formative. Deterministic checks verify structure and behavior; model coaching may cite evidence but cannot score judgment; a trained human later scores the frozen prototype packet. Publication is blocked for personal/confidential data, autonomous high-impact decisions, unsupported financial/HR advice, or deceptive affiliation.

## Two-minute recruiter proof

Open the method contract; invoke one normal case; show the hidden failure and smallest repair; state the human authority boundary and one remaining limitation. The proof must work from a clean session or offline execution sheet.
