## Fixture crosswalk and equivalence

Every pack binds `normal`, `messy`, `non_trigger`, and `hidden` fixture IDs in the JSON file; quiz families are `S04-method-class`, `S04-trigger-boundary`, `S04-io-contract`, `S04-generic-skill`; validator is V03. All use one normal decision, one boundary, one independent run, one changed condition, and one two-minute proof. Domain complexity is balanced by precomputed finance formulas and supplied HR/technical policies.

## Noun-swap test

Each adjacent pack changes at least five authenticity fields: schema, metric/rule, failure, action, authority, verification. Examples: IB reconciles period/unit and creates a deal-team exception; HR suppresses small groups and creates an appealable manager aid; Ops deduplicates an event and routes planner recovery. They share the Method Contract engine, not decision payloads.
