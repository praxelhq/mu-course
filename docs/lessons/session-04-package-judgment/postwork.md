# S04 Postwork — Freeze the Method, Name the Trigger v1.0

**Time:** 30–45 minutes. **Due:** before S05. **Supports:** C4, C8; bridge to C5.

1. Resolve the peer defect or log an evidence-based deliberate non-change.
2. Add one second normal and non-trigger fixture; run both in a fresh session.
3. Freeze method package + provenance + local fallback; attach immutable trace.
4. Write a 150-word method card: job, user, input, output, boundary, failure learned.
5. Draft the structured event that should trigger it in S05: event ID, source, required fields, owner, requested action, prohibited action.
6. Complete delayed Form A in `quiz.md`; after feedback use Form B only if assigned.

**Retention prompt:** Without opening your package, write the six Method Contract parts, then compare and correct in another color/text revision. **Evidence upload:** recall attempt, correction, second-run receipts, event payload, frozen version. **Optional extension:** add property-based/adversarial tests; no grade bonus.
