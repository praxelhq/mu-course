# S04 Demo — The Beautifully Wrong CEO Brief v1.0

**Duration:** 7 minutes. **Asset IDs:** S04-DEMO-FOCOS-01, S04-DEMO-TRANSCRIPT-A/B/C. **Synthetic; authored for instruction, 18 July 2026.**

## Setup

Open two clean sessions. Input pack contains six fictional `Northstar Kitchens` initiatives. One request has no owner, one metric is 90 days stale, and `Food Safety Audit` is protected. Never use a learner's company.

## Script

1. **0:00–0:30 prediction:** vote: reliable decision / polished summary / safe stop.
2. **0:30–1:30 mega-prompt:** “Summarize and tell the CEO what to do.” Show cached output A: it deprioritizes the protected audit, invents an owner, and reports stale growth as current.
3. **1:30–2:10 consequence:** click “accept” in mock mode; red banner shows `protected initiative displaced; owner task cannot be routed`. Ask whether better tone fixes it.
4. **2:10–3:30 open bounded method:** show trigger, required fields, priority rule, output schema, citations, missing-input state, CEO approval.
5. **3:30–4:30 clean run:** output B prioritizes two items, holds missing-owner item, preserves audit, cites fields.
6. **4:30–5:15 non-trigger:** “Write a viral slogan.” It declines and names scope.
7. **5:15–6:15 schema change:** fixture C renames `business_impact` to `impact_range`. First run fails visibly. Change adapter/schema only; rerun passes.
8. **6:15–7:00 close:** “A prompt worked for its author. A method survived a stranger, a boundary, and a changed field.”

## Static replay assets

Transcript A includes input, polished wrong output, and consequence banner. Transcript B shows contract + valid output. Transcript C shows schema error → one-line repair → pass. These are text-first and projected at 200% zoom; narration is captioned.

## Assessed-input separation

Northstar Kitchens never appears in assessment packs. Learners receive role-specific schemas and different hidden changes; reproducing the demo's priority rule fails their content pack.
