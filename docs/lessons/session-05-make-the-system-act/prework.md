# S05 Prework — One Event, Two Actions v1.0

**Time:** 20–25 minutes. **Evidence:** execution prediction + event payload. **Supports:** S5-O1, C5.

## Incident

A fictional operations workflow receives the same delay event twice. Both runs look successful. The first creates a planner task; the second creates another task and sends a second supplier notice. No one can tell whether it was a retry or a new incident.

## Prepare

1. Read `source-pack.md`, case S05-CASE-01 (6 min).
2. Label six steps D/M/H/X and justify the one you are least sure about (5 min).
3. Export the S04 method version and draft one trigger event with `event_id`, `type`, `occurred_at`, `source`, required payload, owner, requested action (8 min).
4. Predict one duplicate/timeout/policy failure and the safe state (5 min).

Submit event, allocation, predicted terminal state, prohibited action, confidence. If S04 is unavailable, choose a curated pack. Plain-text/printed and dictated alternatives carry identical evidence; no workflow account is needed.
