# S05 Instructor Runbook — Make the System Act v1.0

**Intent:** replace “more autonomy” excitement with the more surprising experience of a system that earns trust by stopping and recovering.

## Prep

Freeze emulator/connectors, all eleven pack variants, S04 adapter versions, section-salted failures, cached logs, and paper role stations. Test duplicate idempotency and zero-action boundary. Load D/M/H/X anchors. No production credentials. Verify accessible approval route and incident reset.

## Prompts and misconceptions

“What is the unit of work?” “Could this be an exact rule?” “What does the approver see?” “Can this error be retried safely?” “Where is proof nothing happened?” Many nodes ≠ control; a `human-in-loop` label without authority/evidence fails; retry only transient failures; logs are learning evidence; correct safe stop is success.

## Section consistency

Only mock connectors count. Same six mechanical checks and 70/30 anchors. Overrides carry reason/evidence. Alerts: action-before-approval, duplicate action, missing correlation/log, PII/secret, approval latency, learners blocked >7 min, section incident cluster. Do not reward node count, vendor complexity, or speed.
