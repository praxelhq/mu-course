# S05 Solution and Scoring Anchors v1.0

## Common 70%

| Level | Anchor |
| --- | --- |
| Verified | one event/unit; explicit D/M/H/X; valid state transitions; checked model output; informed human gate; one sandbox action; reconstructable log; hidden failure correctly classified/repaired; replay proves no duplicate/unsafe action |
| Pass | normal and boundary runs pass with approval/log; recovery may be less elegant but safe and inspectable |
| Partial | happy path works but approval lacks information, log cannot reconstruct state, or retry/idempotency weak; zero unsafe action |
| Fail | node theatre, model used for exact rule, no boundary run, duplicate action, or cosmetic failure explanation |
| Unsafe | production connection/secret/PII; autonomous high-impact/outbound action; approval bypass; evidence erased |

## Pathway 30% pass / fail

Consulting: measurable pilot/client authority / generic tracker task. FOCOS: owner/cadence/non-priority / auto budget commitment. Product: release evidence/fallback / feature completion proxy. IB: filing→field→exception/senior approval / silent client-model update. VC: disconfirming evidence/IC boundary / public recommendation. Corp Fin: scenario/downside/CFO control / magic allocation. HR: minimization/fairness/appeal / ranking or invisible adverse action. Ops: SLA-cost-safety/idempotent recovery / duplicate or cost-only action. Sales: verified signal/claim/opt-out/seller approval / auto-send. Marketing: locked claim/brand/hypothesis / publishing unsupported creative. Data: schema/lineage/validity/owner alert / releasing failed metric.

## Moderation

Disagreement typically concerns whether an approval is meaningful. Moderator checks approver identity, evidence visible at decision, available choices, rationale, action gating, and appeal/escalation—not whether a workflow node is labelled “human.” Complexity and vendor fluency do not increase score.
