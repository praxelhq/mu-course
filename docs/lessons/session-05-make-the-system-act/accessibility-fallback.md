# S05 Accessibility and Reliability Route v1.0

State machine, events, approval, action, and logs have structured-text/table views; keyboard and screen-reader controls expose current state and available legal transitions. No drag-only nodes, color-only status, voice, rapid response, production account, or coding is required. Extra time uses pause/resume and equivalent hidden variants; written approval/defence equals spoken.

Offline: event envelopes move through labelled D/M/H/X stations; a cached output card stands for model; approver selects approve/edit/reject; an action token registry enforces one action; paper ledger records state. Sealed failure cards and before/after ledgers preserve parity. Deferred upload carries incident ID/timestamp.

Facilitator activates on request or outage without diagnostic disclosure. Connector/model/LMS failure is `unavailable`; use mock/static evidence. PII/secret triggers quarantine, synthetic replacement, and safe incident log without copying content.
