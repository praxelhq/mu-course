# S02 Instructor Runbook — Build the Evidence Engine

**Asset ID:** `S02-INSTRUCTOR-v1.0` · **Protected action:** 75 minutes

**Intent:** make polished unsupported research feel viscerally risky, then give learners a reproducible chain that restores justified confidence.

## Setup

Freeze source/data/contradiction versions; verify cached accessible excerpts, formula sheets, V01, spreadsheet and offline calculator route. Display: **“Would you forward a claim you cannot reproduce?”** Keep contradiction IDs hidden until v0 freeze.

| Time | Move | Room/evidence check |
| --- | --- | --- |
| 0–6 | three-snippet source choice; lock rationale/confidence | prediction, not source-count popularity |
| 6–15 | audit polished memo: unsupported citation + denominator + mixed period | room confidence should fall for a reason |
| 15–22 | decompose “AI killed the business” into fact/calculation/inference/missing causes | no causal shortcut |
| 22–29 | draw Claim Chain; repair one narrower claim | exact locator and formula visible |
| 29–43 | circulate on decision questions and source triage | ≥1 primary + contrast; snippets lead-only |
| 43–57 | extraction build | raw preserved; unit/period/transformation present |
| 57–68 | calculation build | no hard-coded result; decision relevance stated |
| 68–75 | validate/freeze | debrief only top two mechanical defects |
| 75–82 | release seeded contradiction; require prediction first | no silent row deletion |
| 82–99 | repair; accept honest unresolved hold | downstream claim/decision changes visible |
| 99–106 | blind peer reproduction | reviewer does not receive answer cell |
| 106–111 | freeze dossier | provenance and synthetic label pass |
| 111–118 | individual two-source transfer | basic calculator only; no research model |
| 118–120 | “I believed/evidence/change/uncertainty” exit | bridge to corpus scope |

Prompts: “Show me the exact words”; “What is the denominator?”; “Is this observed, calculated or inferred?”; “What changes in the decision?”; “Why do these sources disagree?”; “Would an honest hold be safer?”

Across sections use fixed equivalence groups and the same contradiction mix. Scaffold locators/formula menu reduce mechanics, not evidence burden. Advanced extraction earns no bonus. If source/parser/network fails, issue the matching cached snapshot; if validator is wrong, preserve attempt and override with reason. Human scorer owns interpretation; peer only reproduces and flags.
