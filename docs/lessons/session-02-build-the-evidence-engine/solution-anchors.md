# S02 Solution Anchors — Evidence Before Eloquence

**Asset ID:** `S02-ANCHORS-v1.0`

## 70% common

- **Pass:** exact primary/contrast locators; raw and normalized values; unit/period/transformation; visible reproducible formula; calibrated claim type; counter-hypothesis; contradiction retained/classified; all downstream changes traced; peer reproduces.
- **Partial:** arithmetic correct but source weak, locator imprecise or caveat generic; contradiction noted but decision implication unchanged without reason.
- **Fail:** bibliography without chain; snippet as source; hard-coded result; percent/points confusion; deleted conflict; synthetic scenario asserted as company fact; polished causal story from association.
- **Unsafe:** confidential/personal data, unauthorized scraping, fabricated citation/number, or unqualified regulated recommendation. Quarantine.

Pass example: “In this labelled synthetic scenario, recoverable exceptions account for 42/120 cases (35%; exact row IDs). This supports testing triage, not claiming company-wide savings; duplicate-row injection lowers it to 33.6%.” Fail: “AI could reduce disruptions by 35% according to our research.”

## 30% pathway anchor and moderation

Pass uses the corresponding pack’s calculation, business rule and authority; fail swaps nouns onto generic summarization. IB requires traceable valuation inputs; VC separates verified/unverified metrics; Corp Fin exposes assumptions; HR includes denominator/fairness; Operations handles duplicates; Sales avoids intent/causal claims; Marketing labels sample inference; Data handles definition drift; Consulting/FOCOS connect evidence to client/owner decision.

Likely disagreement: whether an honest unresolved result deserves a high score. It does when conflict is correctly diagnosed, evidence preserved and decision appropriately held; it does not when “uncertain” hides missing work. Moderator inspects chain completeness, not conclusion boldness. No credit for code, source volume or prose polish.
