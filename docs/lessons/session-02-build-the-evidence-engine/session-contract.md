# S02 Session Contract — Build the Evidence Engine

**Asset ID:** `S02-CONTRACT-v1.0` · **State:** Authored · **Preserves:** L02-O1–O6; C2, C8, C9

## Promise, mechanism and evidence

The learner turns one consequential question into a reproducible Claim Chain: `question → source → extraction → structured data → calculation → claim → decision`. A planted contradiction must survive in the audit trail and change the chain or produce an honest hold.

**Outcome:** classify sources; extract 5–12 decision-relevant rows with lineage; reproduce one original calculation; distinguish fact/calculation/inference/assumption; resolve date/definition/scope/provenance/arithmetic conflict; defend what changed.

**Portfolio:** evidence dossier v1, raw snapshot, dataset + dictionary, calculation, claim ledger, thesis v1, contradiction receipt and recruiter proof.

| Evidence gate | Validator | Release standard |
| --- | --- | --- |
| pre-link source prediction | `V01` — local prediction check | committed before links open |
| source/data/calculation chain | `V01` | locators, raw/normalized values, units, period, transformations and visible formula |
| contradiction repair | `V01` — local repair check | both sources retained; downstream links updated or decision held |
| peer reproduction | `V01` — local reproduction check | reviewer reaches result within stated rounding without answer |
| unseen transfer | `V01` — local ownership/transfer check | identifies broken link and calibrates claim in 7 minutes |

The 70% common score covers provenance/lineage, data/calculation reproducibility, claim calibration, contradiction handling and ownership. The 30% anchor is the pathway calculation/decision implication in `content-packs.md`.

**Quiz integration:** entry/delayed checks use `S02-support-match`, `S02-source-rank`, `S02-calculation-audit`, and `S02-contradiction-response` from `quiz.md`. A quiz pass never overrides a broken or fabricated Claim Chain.

## Dependencies and boundary

Requires S01 brief, metric, guardrail and source-plan seed or an assigned same-stream pack. S03 receives a safe 3–6-document corpus, source metadata, claim ledger and explicit missing evidence. Public/licensed/cached or labelled synthetic evidence only; no unauthorized scraping, personal/confidential data, causal overclaim or synthetic-company-fact claim. No paid tool or code required.
