# S01 Pre-work — Spot the Beautiful Non-Project

**Asset ID:** `S01-PREWORK-v1.0` · **Time:** 23 minutes · **Supports:** C1 · **No paid account**

## The cold open

Read these two fictional proposals:

- **A:** “Build an AI CEO copilot for a famous company. It reads everything, predicts every problem and improves decisions.”
- **B:** “For a shipment-exception planner, classify delayed orders from a supplied synthetic event feed, show the applicable rule and confidence, and require planner approval before rerouting. Success: 30% faster triage with zero duplicate actions.”

Without asking AI, commit:

1. Which would you show a recruiter? Why? (`40–80` words)
2. What fact would make you reverse your choice?
3. Confidence, `0–100`.

Then spend ten minutes observing one recurring task in your target role. Complete: “A **[role]** repeatedly decides **[decision]** using **[evidence]**; a bad decision harms **[metric/stakeholder]**.” Use the remaining five minutes to draft: “I would test **[thin input → output]**; **[named owner]** keeps authority; success/failure is visible when **[test]**.” Do not choose a vendor or claim private access.

## Completion evidence

Submit `S01-PRE-PRED`: A/B choice, reversal evidence, confidence, target role, decision sentence and the three-field draft. This is the draft Work Sample Brief prerequisite; an assigned pathway card replaces it if missing or unsafe. It freezes when class begins. Copying a generated role description does not earn completion.

## Accessible alternative and privacy

The full task is plain text and printable. Audio response with transcript, typed response, or scribe-supported response are equivalent. Use no employer files, personal data or claimed internal knowledge. If the role is undecided, choose one supplied pathway card; the choice is reversible after Session 1.
