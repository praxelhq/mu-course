# S01 Instructor Runbook — Find the Leverage

**Asset ID:** `S01-INSTRUCTOR-v1.0` · **Run exactly:** 120 minutes · **Build:** 74 minutes

**Intent:** replace fashionable solution-first confidence with a decision-first frame that a recruiter can test and a human owner can safely govern.

## Before students enter

Verify stream cards/hidden variants, captions/transcript, freeze/reveal, V00, projector and offline envelopes. Put the question on screen: **“Which smaller project would you trust with a real decision?”** Never reveal constraint allocation before v0 freeze. Use cached demo; never debug a tool in front of the room for more than 45 seconds.

## Run of room

| Time | Instructor move | Expected learner evidence / room check |
| --- | --- | --- |
| 0–5 | force A/B choice and reversal evidence | >90% prediction commits; no debate |
| 5–12 | run polished CEO-copilot, expose missing owner/data/test; contrast narrow exception triage | students can name why polish failed |
| 12–20 | Chegg provocation: substitution, augmentation, redesign or story? | verbs become decisions, not “use AI” |
| 20–29 | draw the nine-link opportunity stack | learners locate their weakest link |
| 29–34 | reject one wrong brief live; make smallest correction | demonstrate “not yet,” not ideation theatre |
| 34–58 | circulate: owner/decision first, system last | 80% reach two observable tests |
| 58–65 | freeze v0; debrief top two heat-map defects | do not coach hidden failures in advance |
| 65–72 | reveal one constraint; require prediction before editing | diagnosis captured |
| 72–92 | coach with questions only; insist on named authority | substantive diff visible |
| 92–101 | pair attack across roles | one finding and one author response |
| 101–108 | freeze v1 and receipt | safety flags remain blocked |
| 108–112 | four rapid retrieval scenarios | correct feature/metric/evidence/authority distinctions |
| 112–119 | unseen individual transfer | no model, no own brief, no peer coaching |
| 119–120 | exit evidence need | bridge to source plan |

## Exact prompts and misconceptions

- “Who acts differently on Monday?” when the company is called the user.
- “Remove the tool noun. What job remains?” for chatbot-first briefs.
- “Faster output causes what outcome?” for time-saved claims.
- “Which named person can stop or appeal this?” for generic human-in-loop.
- “What can you prove without the company?” for prestige/access dependence.

Celebrate a strong narrowing, honest safe stop, or evidence-driven repair—not scope, company fame or technical complexity.

## Section consistency and recovery

Release variants by deterministic allocation; capture seed/version. Scaffold cards may simplify mechanics but not decision/evidence burden. Advanced learners receive ambiguity, not extra marks. A lead instructor alone can run paper groups of five; assistants resolve access only. Any unsafe brief is quarantined, assigned a same-stream fallback, and routed for human review. End with the same transfer conditions in all eight sections.
