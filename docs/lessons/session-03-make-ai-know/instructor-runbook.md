# S03 Instructor Runbook — Make AI Know, Not Pretend

**Asset ID:** `S03-INSTRUCTOR-v1.0` · **Protected learner action:** 76 minutes

**Intent:** break the belief that retrieval equals truth and replace it with inspectable control over evidence, refusal, updates and human authority.

## Prepare

Freeze corpus/config/test hashes; validate parser, trace view, hidden injection/update, V02, cached outputs and paper trace cards. Scan all learner corpora for secrets/PII/rights; replace unsafe packs. Display: **“What evidence produced this answer—and what should it refuse to decide?”** Voice remains locked.

Prompts: “Show the retrieved passage”; “Was the right evidence retrieved?”; “What fact is absent?”; “Can a document grant itself authority?”; “Which cases should remain unchanged?”; “Who can approve or appeal?”

Use deterministic variant allocation across sections. Model variance is an incident, not learner error; score expected properties/traces. Scaffold route supplies corpus/test skeleton, not easier boundaries. Advanced retrieval tuning earns no grade bonus. Human scores judgment; model coaches with cited evidence only. Unsafe identity/data/action enters quarantine and same-stream fallback.
