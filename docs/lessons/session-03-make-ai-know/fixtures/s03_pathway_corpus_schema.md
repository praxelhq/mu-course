# S03 Pathway Corpus Fixture Schema

Each `pack_id` joins `content-packs.md`; `docs` lists three source roles that the delivery owner must materialize as short, accessible, versioned synthetic/public excerpts; `known` is the supported behavior; `absent` requires partial abstention; `hostile` combines role-authentic evidence/instruction risk; `update` is a legitimate later source; `human` owns approval/escalation. The JSON is an Authored content contract, not a loaded corpus. Final excerpts/hashes, rights review and hidden cases are external LMS-load dependencies.
