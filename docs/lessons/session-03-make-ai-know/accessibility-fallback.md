# S03 Accessibility, Static Trace and Outage Route

**Asset ID:** `S03-ACCESS-v1.0`

- Documents, passages and traces have accessible text, stable IDs and linear reading order; no network graph or color is required.
- Test-builder is keyboard operable with labelled category/property fields; results announce retrieved IDs and pass/fail reasons.
- Demo is captioned/transcribed; response differences are reproduced as text tables.
- Voice is optional, never required as input/output, and no identity resemblance is graded.
- Peer held-out can be typed or screen-reader mediated; approved extra time preserves clean-session/no-coaching rules.
- Low-bandwidth uses locally cached corpus and result JSON. Full outage uses numbered document/query/passage/response cards and regression matrix.
- Parser failure uses pre-parsed corpus bound to the same hash. Model outage uses deterministic cached responses/traces; learners still predict, classify, repair and transfer.

Activate for accommodation or >60-second blocking service incident. Evidence parity: prediction, manifest/config/test versions, baseline, hostile reveal, diagnosis, repair, regression, peer and legitimate update. Facilitator stamps/imports receipts; platform incidents never count as learner failure. Device/AT rehearsal and institutional approval remain external.
