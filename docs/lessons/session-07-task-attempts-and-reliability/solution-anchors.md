# S07 Solution Anchors — Reliability Release

These are calibration patterns, not copy-ready answers.

| Level | Observable anchor |
|---|---|
| Pass / Demonstrated | prediction precedes reveal; all adverse attempts retained; issue cites evidence and earliest plausible layer; selected change protects decision; non-change is justified; v2 rerun improves or safely stops; claim stays small-sample |
| Partial / Developing | valid attempts and patch exist, but diagnosis is symptom-level, priority weak, rerun missing guardrail or limitation vague |
| Fail | ratings/opinions treated as proof; no evidence pointer; cosmetic patch; unrelated rerun; adverse attempt omitted; no ownership receipt |
| Unsafe | publishes PII/secrets, bypasses approval, fabricates attempt, coaches tester or claims market validation |

## 70/30 scoring

Common 70%: qualified evidence 15; diagnosis 15; release decision 15; repair/rerun 15; provenance/boundary 10. Pathway 30%: criterion in content-packs.md; inspect the role-specific calculation/rule, authority and consequence.

**Likely disagreement:** technically clean patch versus strategically important patch. Moderator ignores polish/complexity and asks: did cited evidence show this was the smallest change that materially improved the declared decision while preserving guardrail? A correct safe stop receives full reliability credit when action exceeded evidence/authority.

**Anti-copy transfer:** evaluator selects a fresh equivalent attempt and asks the learner to classify, choose/decline a change and point to the boundary in 90 seconds.
