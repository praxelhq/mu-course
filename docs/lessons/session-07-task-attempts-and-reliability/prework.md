# S07 Pre-work — Two Stars, One Dangerous Success

**Time:** 18 minutes · **No paid account** · **Evidence:** S07-PRE-01 prediction receipt

## The setup

Your prototype has two assigned attempts. One tester says “easy, 5/5”; another says “looks useful.” Neither statement proves the task worked.

1. Re-open the Session 6 acceptance contract and identify the one outcome whose failure would change a real decision (3 min).
2. Inspect only the two supplied attempt summaries—not the author feedback—and label each observation behavior, opinion, system evidence or noise (6 min).
3. Commit: “If I had to release now, I would change ___ because ___; confidence __/100.” Name the log/event that would overturn you (5 min).
4. Confirm v1/replay opens and contains no secrets/PII; otherwise request S07-FB-01 before class (4 min).

Do not alter v1 after the exchange freeze. The LMS hashes the acceptance contract and v1. The prediction remains hidden from peers.

**Accessible alternative:** same material as linear HTML, tagged PDF or printed large-text sheet; event evidence may be a table instead of screenshots. Screen-reader and extended-window routes are equivalent.
