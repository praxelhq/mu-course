# S07 Demo — The Five-star Failure

**Length:** 6 minutes · **Assets:** S07-DEMO-ACCEPT, D-A/D-B/D-C in synthetic fixture; three static frames for fallback.

1. Show ratings 5/5, 4/5, 5/5. Ask learners to vote: improve visuals, shorten copy, fix approval routing, or ship. Freeze vote.
2. Open acceptance contract: “route a high-risk refund to an approver and preserve evidence.”
3. Reveal D-A: completed while skipping approval; D-B: abandoned after an ambiguous field; D-C: confidently invented policy.
4. Classify D-A workflow/policy, D-B interface, D-C grounding/method. Make the earliest broken layer visible.
5. Prioritize D-A by decision consequence despite no complaint. Add approval gate; rerun equivalent D-A2; show safe escalation receipt.
6. Reject the visual redesign: no evidence it blocks the core decision. Say: “This supports one safer release, not product-market fit.”
7. Transfer question: “If ratings were all 1/5 but the task completed safely, what would you inspect before changing?”

**Static replay:** frames show contract, ratings/log conflict and before/after state. Instructor reads timestamped transcript; students make the same vote and classification.
