# S06 Accessibility and Reliability Route v1.0

Every form has a semantic text/replay equivalent; keyboard path, visible focus, named errors/recovery, 200% zoom, screen-reader labels, chart tables, captions/transcripts, reduced motion. No drag/hover/color/voice/video/public posting/rapid typing is required. Written defence equals spoken; extra time preserves immutable freeze and equivalent variant.

Offline/clickable route preserves input, method/control operation, human decision, output, event log, independent tester, safe failure and release decision. Pair device is allowed with independent tester identity. Builder/host/model/connector/LMS outage becomes `unavailable`; switch to shell/replay/cached output and attach incident receipt. Broken endpoint never penalizes tester or author when replay evidence is sound.

Secrets/PII trigger quarantine, removal/rotation, synthetic replacement and rerun. Public hosting may be declined for privacy/safety; private proof/replay satisfies the same learning evidence.
