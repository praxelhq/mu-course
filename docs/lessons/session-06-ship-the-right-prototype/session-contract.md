# S06 Session Contract — Ship the Right Prototype v1.0

**State:** Authored; self-audit in `self-audit.md`. **Duration:** 120 live + 45–60 postwork. **Capabilities:** C6, C8; integrates C4–C5. **Canonical outcomes:** L06-O1–L06-O6 (aliases S6-O1–S6-O6). **Canonical validator:** V05; all local checks nest under it.

## Promise and common mechanism

Ship the smallest surface that lets a fresh role-card user complete one consequential task and lets the owner observe success or safe failure. `Work need → form choice → precommitted acceptance → thin integration → task attempt → evidence-led release`.

## Evidence and portfolio

Form-selection decision + rejected form; three pre-build tests; reachable URL or immutable replay; S04/S05 version links; normal and safe-failure traces; independent assigned attempt; structured event/log; revision or deliberate no-change; disclosure/provenance; release note. This is Prototype v1, not a landing page.

## Dependencies and boundaries

Frozen/replayable S04 method and S05 execution; supported shells across app, workflow, grounded assistant, dashboard/model, data surface; mock actions only. Demo `S06-DEMO-NEUTRAL-01` uses a different task from assessed pathway packs. Public deployment is optional; replay parity is guaranteed.

## Proof

In two minutes: name role/job; run one input through the chosen surface; point to result + event/log; show safe failure; state human action and one limitation. A screenshot, page view, polished UI, code complexity, or friendly praise cannot satisfy the proof.
