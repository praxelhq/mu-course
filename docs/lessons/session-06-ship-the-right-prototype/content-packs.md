## Crosswalk, equivalence, anti-skin

Quiz families `S06-D-01`, `S06-R-01/02/03`; validator V05; anchors in `solution-anchors.md`. Each pack supplies a visible normal task, visible boundary self-test, and author-hidden changed/unsafe task for the fresh assigned attempt. Mechanical build load is equalized with prewired form shells and precomputed finance functions. Each row changes at least five of schema, metric/rule, failure, action, authority, proof; a generic chatbot or landing page cannot pass multiple rows by noun substitution.
