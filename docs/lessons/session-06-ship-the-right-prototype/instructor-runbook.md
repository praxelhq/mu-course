# S06 Instructor Runbook — Ship the Right Prototype v1.0

**Intent:** create the aha that a plain, role-fit surface with proof beats a beautiful generic app. At least 79 minutes are learner action.

## Prep

Freeze equal-quality shells/replays for five forms, mock adapters, pathway packs, tester matching, section variants, telemetry, cached demo, paper clickable routes. Test each pack's visible N01/B01 tasks and author-hidden H01 assigned task, keyboard, zoom, screen reader, secrets scan. Ensure student projects can fall back to curated core without losing judgment evidence. Do not allow public/prod connections.

## Coach against traps

Website default → “who does what next?” Feature sprawl → one task under three minutes. Screenshot → fresh run ID. Likeability → completion/failure evidence. Telemetry later → add before tester. Broken generated code → roll back shell. Replay stigma → grade inspectability. Safe failure hidden → make it the release story.

## Consistency and alerts

All forms share identical common evidence; visual polish gets zero independent points. Alerts: no precommitted test, broken method/control link, no log, unsafe input action, author coaching tester, secret/PII, inaccessible route, endpoint incident, assignment conflict. Overrides need evidence/reason. Human scores judgment later.
