# S08 Demo — One Evidence Base, Three Decisions

**8 minutes; neutral synthetic release S08-DEMO-01.**

1. Display a verified result: approval defect fixed; rerun 8/8; one latency limit remains. Ask which stakeholder needs what action.
2. Flash a CFO note (fund pilot), frontline runbook (handle exceptions), and 20-second campaign storyboard (test a customer promise). Students name what changes and what must remain.
3. Build a six-screen executive update: decision; evidence; failure; fix; risk; ask. Every screen points to CLM-D1/D2/D3.
4. Press the “one-click video” route. Reveal invented “50% faster,” absent disclosure and inaccessible audio-only claim. Freeze reaction.
5. Repair: storyboard first; remove invented number; attach evidence IDs; add synthetic-media disclosure, captions and alt text; keep human approval.
6. Inject “CFO gives 30 seconds and bans customer logos.” Remove decorative screen/logo, not evidence/limit; recheck action.
7. Transfer prompt: “If the stakeholder is now the operator, which artifact changes—and which claim cannot?”

Static fallback provides six printable screens, storyboard frames and transcript; learners still predict, identify the false claim and make the constraint edit.
