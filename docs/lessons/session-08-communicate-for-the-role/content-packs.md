# S08 Content Packs — Role Communication

All packs use V07, three locked claims, one constraint repair, blind scan and equivalent proof. Fixture S08-FX-CLAIMS-01 is synthetic. Format is a professional decision surface, not a cosmetic skin.

| Pack ID | Role/mode; stakeholder→approver | Payload/metric + required artifact | Hidden constraint/failure → action/boundary | Proof / 30% judgment |
