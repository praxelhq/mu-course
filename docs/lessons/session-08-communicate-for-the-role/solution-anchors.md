# S08 Solution Anchors — Communication Under Constraint

| Level | Evidence pattern |
|---|---|
| Pass | stakeholder/action/format committed; all three claims trace; constraint prediction is specific; v2 changes the right element while preserving evidence/boundary; blind reviewer identifies action/evidence/limit; rights/access/disclosure pass |
| Partial | credible artifact but action late, one weak claim link, generic constraint response or reviewer misses limitation |
| Fail | generic pitch deck/video, invented claim, format chosen for novelty, no before/after evidence or coached scan |
| Unsafe | unauthorized likeness/voice, unlicensed/private asset, misleading affiliation, hidden synthetic media, removed human boundary |

Common 70%: action/format 15; evidence lock 20; constraint repair 15; blind scan/usefulness 10; provenance/access 10. Pathway 30% follows content-packs.md.

Likely disagreement is “beautiful and persuasive” versus decision-useful. Moderator covers the title/branding and asks: can the stakeholder state the requested action, trace the decisive claim, see uncertainty and retain authority? A plain memo can beat a film. Transfer uses a fresh stakeholder/time/access constraint; learner has 90 seconds to specify what changes and what remains invariant.
