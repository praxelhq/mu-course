# S08 Simulator Spec — Stakeholder Studio

**Mission:** S08-SIM-01 · **Validator:** V07

BRIEF_READY → ACTION_COMMITTED → CLAIMS_LOCKED → V1_BUILT → CONSTRAINT_REVEALED → CONSEQUENCE_PREDICTED → V2_REPAIRED → BLIND_SCAN → RIGHTS_ACCESS_AUDIT → FROZEN. Side states: MEDIA_FALLBACK, CLAIM_QUARANTINED, ACCESS_REPAIR. Illegal: generate before action/format commitment; edit locked fact without versioned evidence; reveal reviewer role early; publish unlicensed/undisclosed media.

Learner chooses action/format, manipulates claim order/storyboard, directs supported generation, receives a pathway-specific constraint, repairs and submits to a blind reviewer. Constraint changes attention, stakeholder, risk, legal, brand or accessibility state; it never merely changes color.

Feedback: deterministic V07 checks dimensions, claim links, locked constraints, rights/disclosure and accessibility; model coach cites exact artifact/evidence spans and asks one repair question; blind peer reports perceived action/evidence/limit only; trained human scores stakeholder and stream judgment. No model final grade.

Hidden assessed claim/constraint differs from demo. Replay resets to v1 and retains history. Facilitator can pause media, issue static assets, quarantine a claim and extend accessible timing, never choose the format.

Events: communication_contract_saved; format_decision_committed; claim_lock_frozen; artifact_v1_saved; constraint_revealed; constraint_prediction_committed; artifact_v2_saved; stakeholder_scan_submitted; rights_access_scan_completed; V07_result; communication_pack_frozen. All include version, pathway, section, privacy and idempotency key.

Offline: printed evidence lock, blank six-panel/memo/runbook canvas, sealed constraint, blind paper scan and red-pen revision preserve every assessed decision.
