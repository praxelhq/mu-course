## Common loading order

1. bind session contract, canonical outcomes and validator;
2. load eleven pathway cards and structured fixtures;
3. separate learner-visible, reveal-gated, hidden and evaluator-only assets;
4. load state/reveal rules and LMS copy/events;
5. load deterministic checks and model-coaching evidence constraints;
6. load quiz forms/keys with containment;
7. activate accessible/offline routes and incident replacement relations;
8. run normal, partial, safe-stop, unsafe, duplicate, malformed, hidden-transfer and outage tests;
9. record signed content version in the operational inventory;
10. rehearse from a real student and facilitator account before section release.
